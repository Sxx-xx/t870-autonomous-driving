1. 목표
-------

ERP42/ROS 1 기반 코드를 Henes Broon T870용 ROS 2 자율주행 파이프라인으로
이식하고, 다음 실제 하드웨어 구성을 반영하였다.

- 비행 컨트롤러: Pixhawk 6C Pro (FMUv6C)
- 자세 센서: Pixhawk 내장 IMU를 주 센서로 사용
- 지자기 센서: IST8310
- GNSS: 고정밀 RTK u-blox ZED-F9P Rover Lite
- LiDAR: SLAMTEC RPLIDAR C1, 360도, IP54
- 조향: RoboClaw Solo 30A
- 구동: Pixhawk RC PWM 채널 3을 통한 Cytron MDD20A 제어


2. 자세 및 위치 추정 방침
------------------------

자세제어는 Pixhawk 6C Pro의 IMU와 PX4 EKF2 출력을 중심으로 한다.

- IMU가 고율 자세 예측과 차량 yaw/attitude 추정의 주 센서이다.
- IST8310 자력계와 F9P의 위치·속도 측정값은 EKF의 저주파 드리프트와
  바이어스를 줄이는 보조 정보로 사용한다.
- ROS 2에서는 MAVROS가 전달하는 Pixhawk EKF quaternion/odometry를 사용한다.
- GPS 측정값만으로 직접 자세를 제어하지 않는다.
- F9P Rover Lite는 UART2/CAN 제약 때문에 dual-F9P moving-baseline heading
  구성에 사용하지 않는다.
- 따라서 GPS yaw 기능 대신 Pixhawk IMU + IST8310 기반 EKF yaw를 유지한다.

주요 입력 토픽:

- /mavros/imu/data
- /mavros/global_position/local
- /mavros/global_position/raw/fix
- /mavros/gpsstatus/gps1/raw
- /mavros/estimator_status


3. 구현된 자율주행 파이프라인
---------------------------

[Pixhawk IMU + IST8310 + F9P]
              |
              v
        PX4 EKF2 / MAVROS --------+
                                  |
[RPLIDAR C1] -> /scan             v
                         RTK/센서 상태 검사
                                  |
                                  v
                        MaRRT 로컬 경로 계획
                         /waypoints, /rrt_path
                                  |
                                  v
                      Pure Pursuit + 속도 PID
                              /cmd_vel
                                  |
                                  v
                    RoboClaw 조향 + Pixhawk PWM


4. 패키지별 구현 내용
--------------------

4.1 sllidar_ros2

- SLAMTEC 공식 ROS 2 드라이버를 추가하였다.
- RPLIDAR C1 설정:
  - 통신 방식: serial
  - 기본 포트: /dev/rplidar
  - baudrate: 460800
  - frame_id: laser
  - scan_mode: Standard
  - 출력 토픽: /scan
- base_link에서 laser까지의 정적 TF를 통합 launch에서 발행한다.
- lidar_x, lidar_y, lidar_z, lidar_yaw를 실제 장착 위치에 맞게 변경할 수 있다.

4.2 mavros / mavros_msgs / mavros_extras / libmavconn

- ROS 2 Jazzy용 MAVROS 2.14.0 소스를 추가하고 빌드하였다.
- MAVLink 개발 패키지가 설치된 뒤 기존 mavlinkConfig 탐색 오류가 해결되었다.
- Pixhawk의 IMU, EKF odometry, GNSS, RTK fix type 및 estimator 상태를 ROS 2에
  전달하도록 사용한다.
- mavros_extras의 gps_rtk 등 RTK 관련 플러그인도 정상 빌드되었다.
- MAVROS 자체는 통합 launch 밖에서 Pixhawk 연결 주소에 맞춰 먼저 실행한다.

4.3 ma_rrt_path_plan

- ROS 2용 MaRRTPathPlanNode를 구현하였다.
- /scan의 장애물 점을 차량 자세와 LiDAR 장착 오프셋을 사용해 세계 좌표로
  변환한다.
- 차량 전방에 로컬 목표를 만들고 RRT로 충돌 회피 경로를 생성한다.
- 계획 결과:
  - /waypoints: base_link 기준 추종용 경로
  - /rrt_path: map 기준 시각화/확인용 경로
- 기본 계획 주기: 5 Hz
- 다음 조건을 모두 만족해야 유효한 경로를 발행한다.
  - odometry가 최신 상태
  - Pixhawk/IST8310 자세 데이터가 최신 상태
  - PX4 EKF의 attitude, horizontal velocity, absolute position 상태가 정상
  - GPS glitch와 accelerometer error가 없음
  - RPLIDAR scan이 최신 상태
  - GNSS 위치 covariance가 설정 기준 이내
  - F9P fix type이 RTK FIXED
- 조건이 깨지면 빈 /waypoints를 발행해 추종 노드를 정지시킨다.

4.4 t870_track

- ROS 1 rospy 의존성을 제거한 ROS 2 추종 노드를 구현하였다.
- T870 축거 1.08 m를 반영한 Pure Pursuit를 사용한다.
- 속도에 따라 look-ahead 거리를 동적으로 조정한다.
- 조향 출력 단위를 degree가 아닌 radian으로 통일하였다.
- 속도 제어용 PID를 구현하였다.
- 제어 주기: 20 Hz
- 입력:
  - /waypoints
  - /mavros/global_position/local
- 출력:
  - /cmd_vel
  - /t870/target_waypoint
- 경로가 비어 있거나 경로/odometry가 오래되면 즉시 0 속도 명령을 발행한다.
- 노드 종료 시에도 정지 명령을 발행한다.

4.5 t870_control

- roboclaw_steering_node를 구현·연결하였다.
- /cmd_vel의 angular.z(rad)를 RoboClaw 위치 명령으로 변환한다.
- /cmd_vel의 linear.x를 Pixhawk RC override 채널 3 PWM으로 변환한다.
- RPLIDAR 전방 부채꼴 영역의 장애물을 감시한다.
- 기본 E-Stop 기준:
  - 거리 1.2 m 이내
  - 전방 좌우 30도
- /scan 또는 /cmd_vel이 0.5초 이상 끊기면 watchdog이 정지시킨다.
- 정지 시 throttle을 0으로 만들고 조향을 중앙으로 복귀시킨다.
- 상태 출력:
  - /t870/steering_angle
  - /t870/current_speed
  - /t870/emergency_stop

4.6 통합 launch

파일:
src/t870_control/launch/t870_autonomy.launch.py

동시에 실행하는 구성:

- RPLIDAR C1 드라이버
- base_link -> laser 정적 TF
- MaRRT 로컬 경로 계획 노드
- T870 Pure Pursuit 추종 노드
- RoboClaw/Pixhawk 구동 노드

launch 인자와 기본값:

- lidar_serial_port:=/dev/rplidar
- roboclaw_serial_port:=/dev/roboclaw
- target_velocity:=1.0
- require_rtk_quality:=true
- lidar_x:=0.0
- lidar_y:=0.0
- lidar_z:=0.35
- lidar_yaw:=0.0

6. 실행 방법
------------

터미널 1: MAVROS 실행

  cd /home/sxx/Desktop/colcon_ws./colcon_ws/colcon_ws
  source /opt/ros/jazzy/setup.bash
  source install_t870/setup.bash

  # 아래 fcu_url은 실제 Pixhawk 연결 장치와 baudrate에 맞춰 변경한다.
  ros2 launch mavros px4.launch fcu_url:=serial:///dev/ttyACM0:921600

터미널 2: 자율주행 파이프라인 실행

  cd /home/sxx/Desktop/colcon_ws./colcon_ws/colcon_ws
  source /opt/ros/jazzy/setup.bash
  source install_t870/setup.bash

  ros2 launch t870_control t870_autonomy.launch.py \
    lidar_serial_port:=/dev/rplidar \
    roboclaw_serial_port:=/dev/roboclaw \
    target_velocity:=0.5 \
    lidar_x:=0.0 lidar_y:=0.0 lidar_z:=0.35 lidar_yaw:=0.0

주의: 첫 시험에서는 target_velocity를 0.5 m/s 이하로 설정하고 실제 장착
오프셋을 입력한다.

8. 실차 투입 전 필수 확인
------------------------

- PX4에서 IMU 기반 EKF2와 GNSS position/velocity fusion을 설정한다.
- dual-GPS heading/GPS yaw 설정은 사용하지 않는다.
- IST8310 방향, compass calibration 및 IMU calibration을 완료한다.
- F9P가 RTK FIXED(fix_type 6)를 지속적으로 유지하는지 확인한다.
- NavSatFix horizontal covariance가 기본 0.15 m 기준 이내인지 확인한다.
- estimator_status의 attitude, horizontal velocity, absolute horizontal
  position flag가 정상인지 확인한다.
- GPS glitch 및 accelerometer error flag가 없어야 한다.
- /dev/rplidar와 /dev/roboclaw udev 고정 symlink 및 사용자 권한을 설정한다.
- LiDAR 장착 위치와 yaw를 실측해 launch 인자에 반영한다.
- RoboClaw 조향 중심값, 최소/최대 potentiometer 값과 조향 방향을 보정한다.
- Pixhawk RC override 채널 3의 중립 PWM과 구동 방향을 확인한다.
- 바퀴를 띄우거나 구동 전원을 분리한 상태에서 먼저 명령 방향을 확인한다.
- LiDAR를 가리거나 토픽을 끊어 E-Stop/watchdog 정지가 실제로 작동하는지
  반드시 시험한다.

결론
----

현재 소프트웨어는 Pixhawk 6C Pro의 IMU/EKF 자세를 주 기준으로 사용하고,
F9P RTK 위치·속도로 누적 오차를 보정하며, RPLIDAR C1 장애물 정보를 이용해
경로를 계획·추종하도록 구성되어 있다. MAVLink 개발 패키지 문제도 해결되어
MAVROS를 포함한 전체 대상 패키지 빌드는 성공했다. 다음 단계는 실제 장비를
연결한 정적 안전 시험과 저속 주행 튜닝이다.
