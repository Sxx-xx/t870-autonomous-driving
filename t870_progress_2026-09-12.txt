2026-09-12 리시버 신호 단절 급정지 강화
============================================================

- 보조 Arduino의 RC PWM 단절 판정 시간을 300 ms에서 120 ms로 단축.
- D4(조향), D5(스로틀), D6(모드) 중 하나라도 120 ms 동안 펄스가
  없으면 connected=false, 조향/스로틀 명령 0을 I2C로 전송.
- 메인 Arduino의 I2C 보고서 갱신 timeout을 300 ms에서 150 ms로 단축.
- 메인에 emergencyStopDrive() 공통 급정지 함수를 추가함.
  리시버 또는 보조 Arduino 통신 단절 시 감속 램프/PI/개루프 명령을
  우회하고 DRIVE_PWM을 즉시 0으로 만들며, 단절 중 매 loop 재적용함.
- 재연결 시 기존 안전 동작 유지:
  1초 정지 유지, MANUAL은 스로틀 중립 확인 후에만 재출발.
- 조향도 기존과 동일하게 리시버/I2C 단절 시 PWM 0으로 정지.
- 주의: 이는 PWM 출력 차단 방식이며 모터 역전제동은 사용하지 않음.
- 컴파일 확인 완료:
  메인 12222 bytes / RAM 1024 bytes,
  보조 5032 bytes / RAM 423 bytes.
- 메인 Arduino(일련번호 34331323136351211280) 업로드 완료.
- 보조 Arduino(일련번호 24238313635351910130) 업로드 완료.
  보조 업로드 첫 동기화 시도에서 일시 경고가 있었지만 자동 재시도 후
  종료 코드 0 및 새 업로드 포트 확인으로 정상 완료됨.
